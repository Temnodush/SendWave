# [![Typing SVG](https://readme-typing-svg.herokuapp.com?font=Press+Start+2P&size=40&pause=1000&color=CE2CF7&center=true&vCenter=true&width=435&lines=SendWave)](https://git.io/typing-svg) 

**SandWave** — современный веб-сервис для управления email-рассылками на Django. Создавайте, планируйте и отслеживайте рассылки с детальной статистикой.

---

## ✨ Возможности

### 📬 Рассылки
- Разовые, ежедневные, еженедельные и ежемесячные рассылки
- Гибкая настройка времени и дней отправки
- Автоматическая отправка по расписанию
- Ручной запуск в любой момент

### 👥 Клиенты
- CRUD операции для получателей
- История отправок для каждого клиента

### 📊 Статистика
- Отслеживание успешных/неудачных отправок
- Персональная и общая статистика
- Журнал всех попыток отправки

### 🔐 Безопасность
- Регистрация с подтверждением email
- Восстановление пароля
- Роли: Пользователь / Менеджер
- Разграничение доступа к данным

### ⚡ Производительность
- Кеширование через Redis
- Bulk-операции для массовых действий

## 🛠 Технологии

| Python 3.14+ | Язык программирования |

## 🚀 Установка

### 1. Клонирование

```
git clone https://github.com/yourusername/sendwave.git
cd sendwave
```

## 🔧 Команды
```
python manage.py send_scheduled   # Отправка рассылок
python manage.py debug_mailing    # Отладка
python manage.py clear_cache      # Очистка кеша
```
